# iInspect — Инспектор ИИ

[Познакомиться с продуктом](https://dmitrykdi.github.io/iInspect-showcase/)

iInspect помогает специалистам сопоставлять строительную документацию, рассматривать возможные расхождения и проверять их по первоисточникам.

## Возможности

- Проектная, рабочая и исполнительная документация в одном рабочем пространстве.
- Удобное сопоставление текстов и чертежей.
- Переход от замечания к исходному документу.
- Решения специалиста с обоснованием и историей.
- Итоги проверки в протоколе.

ИИ предлагает возможные расхождения. Итоговое решение принимает специалист.

На сайте используются упрощённые иллюстрации с условными документами и данными.
